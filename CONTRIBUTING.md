# Contributing to Kumar Commerce Intelligence

Thank you for your interest in contributing to Kumar Commerce Intelligence.

Contributions, bug reports, documentation improvements and suggestions are welcome.

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Set up a compatible Magento 2 development environment.
4. Install the module.
5. Verify that the existing functionality works before making changes.

## Development Guidelines

Please follow these guidelines when contributing:

* Follow Magento 2 coding standards.
* Keep changes focused and maintainable.
* Avoid modifying Magento core files.
* Use Magento module architecture and conventions.
* Maintain existing functionality.
* Avoid introducing unnecessary dependencies.
* Do not include proprietary code or unlicensed assets.
* Do not commit credentials or sensitive store information.

## Submitting Changes

1. Create a feature branch.
2. Implement your changes.
3. Test your implementation.
4. Review your Git diff.
5. Submit a pull request.

## Pull Request Guidelines

Please include:

* A clear description of the change.
* The reason for the change.
* Relevant screenshots for UI modifications.
* Testing details.
* Any compatibility considerations.

## Code of Conduct

Contributors are expected to communicate respectfully and maintain a professional and collaborative environment.

Thank you for helping improve Kumar Commerce Intelligence.
